ให้วางไฟล์ต่อไปนี้ในโฟลเดอร์นี้:

- THSarabunNew-Bold.ttf

- ถ้าไม่ใส่ไฟล์ ระบบจะพยายามใช้ฟอนต์ในเครื่อง (เช่น "TH Sarabun New", "Sarabun", "Tahoma")
  ซึ่งบน Windows ส่วนใหญ่จะมีและยังแสดงไทยได้ แต่บนเครื่อง/เซิร์ฟเวอร์บางแบบอาจไม่ครบ
